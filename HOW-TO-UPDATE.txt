📰 ADDING NEWS POSTS
================================================================================

You do not edit HTML for this anymore, and you do not update two places.

One news post = one Markdown file in content/news/. A generator reads those
files and writes BOTH the article list on news.html and the Recent News
preview on index.html. Neither page is edited by hand.

THE FRONT MATTER (the block at the top, between two lines of ---)

  REQUIRED
    title      The full headline, shown on the News page.
    date       Month precision only, as YYYY-MM. For example 2026-08.
    teaser     One or two sentences. This is what shows on the homepage.

  OPTIONAL
    short_title  A shorter headline for the homepage, for when the real
                 title is long. The News page still shows the full title.
    image        One photo, placed at the top of the post.
    image_alt    Required whenever image is used. Describes the photo for
                 screen readers.

A front matter line is "key: value" split on the FIRST colon, so a colon
inside your title is fine.

WHAT YOU CAN WRITE IN THE BODY

  Paragraphs      Any block of text with a blank line above and below.
  Subheading      A line starting with two hash marks and a space.
  Bulleted list   Consecutive lines each starting with a hyphen and a space.
  Link            [the label](where it goes)
  Bold            Two asterisks on each side of the text.
  Italic          One asterisk on each side of the text.

Links to outside sites automatically open in a new tab. Links inside this
site, and email links, do not. You do not have to think about it.

WHAT IS NOT ACCEPTED

Numbered lists, nested lists, tables, block quotes, backtick code, image
syntax in the body, raw HTML tags, and any heading other than the two hash
mark form. A lone asterisk in your prose is also rejected, because the
generator reads it as an unfinished italic marker.

None of these silently break the page. The generator stops and tells you the
file and the line number.

HOW TO ADD A POST, START TO FINISH

1. Make a branch. Never commit straight to main.
2. Copy content/news/_template.md to content/news/your-post-name.md
     Use lowercase letters, numbers, and hyphens only in the file name.
     Convention: start with the year and month, like 2026-09-aag-talk.md
3. Edit the front matter and replace the body text.
4. Commit and open a pull request against main.
5. An automated check runs and adds a commit with the regenerated pages, so
     the reviewer sees exactly how it will look.
6. Ask for review. Merging is what publishes it.

You need collaborator access to the repository. You do NOT need any password,
login, or credential belonging to Dr. McWhorter.

TO PREVIEW IT YOURSELF (optional)

  python scripts/generate_news.py           regenerate both pages
  python scripts/generate_news.py --check   check without changing anything

Nothing to install and no internet needed, just Python 3.

⚠️  THE ONE THAT WILL TRIP YOU UP: DASHES

The generator REJECTS the em dash and the en dash. Microsoft Word and Google
Docs silently turn a typed hyphen into an em dash, so a draft written in
either almost certainly has some, and you cannot really see them.

If a post is rejected for this, the error quotes the exact line. Replace the
character with a comma, a colon, or the word "to" for a range like 2024 to
2026.

To stop it happening:
  Word         File > Options > Proofing > AutoCorrect Options >
               AutoFormat As You Type, and clear the hyphens to dash option.
  Google Docs  Tools > Preferences, and clear Automatic substitution.
  Either one   Paste as plain text when moving a draft into the file.

THE HOMEPAGE PREVIEW IS AUTOMATIC

The old version of this guide told you to also copy the two newest posts into
the Recent News section of index.html by hand. Do not do that anymore. It is
generated. Editing it by hand will just be overwritten on the next run.

How many posts it shows is set by PREVIEW_COUNT near the top of
scripts/generate_news.py. Change that one number and the homepage follows.

📸 ADDING PHOTOS
================================================================================

PEOPLE PHOTOS:
1. Save photo to: images/ folder
2. Recommended size: 300x300px (square works best)
3. In people.html, replace the placeholder div:

   FROM:
   <div class="person-photo-placeholder">
       <span>Photo</span>
   </div>

   TO:
   <img src="images/firstname-lastname.jpg" alt="First Last" class="person-photo">

4. Add this CSS to styles.css (only need to do this once):

   .person-photo {
       width: 140px;
       height: 140px;
       border-radius: 50%;
       object-fit: cover;
       margin: 0 auto 1.5rem;
       display: block;
       border: 3px solid var(--accent);
   }

NEWS PHOTOS:
- Already styled! Just use class="news-image"
- Recommended: landscape orientation, max 800px wide

PET PHOTOS:
- Same as people photos, they're good bois and girls

🌐 WHEN YOU'RE READY TO LAUNCH
================================================================================

1. UPDATE YOUR DOMAIN in sitemap.xml:
   Replace "https://yourdomain.com" with your actual URL
   (e.g., https://geospatialcognitionlab.github.io)

2. CREATE A FAVICON:
   - Make a 32x32 or 64x64 pixel version of your logo
   - Save as: images/favicon.png
   - Already referenced in all pages!

3. SWITCH FROM COMING SOON:
   - Option A: Rename coming-soon.html to something else, rename index.html
   - Option B: Just share the index.html URL directly
   - For GitHub Pages: index.html is automatically the homepage

4. UPDATE OPEN GRAPH IMAGE:
   In index.html, update this line with your full URL:
   <meta property="og:image" content="images/logo-square.png">
   TO:
   <meta property="og:image" content="https://yourdomain.com/images/logo-square.png">

👥 ADDING NEW TEAM MEMBERS
================================================================================

1. Open: people.html
2. Copy an existing person-card div
3. Paste it in the grid
4. Update: name, title, bio, photo, links

For the PI card (slightly different styling):
- Use class="person-card person-card-pi"

For regular members:
- Use class="person-card"

ADDING PROFILE LINKS (Website, Scholar, LinkedIn, etc.):
Inside each person-card, there's a person-links div. Add/remove links as needed:

   <div class="person-links">
       <a href="https://their-website.com" class="person-link">Website</a>
       <a href="https://scholar.google.com/citations?user=THEIR_ID" class="person-link">Scholar</a>
       <a href="https://linkedin.com/in/their-profile" class="person-link">LinkedIn</a>
   </div>

Common link types:
- Personal website: Just use their URL
- Google Scholar: https://scholar.google.com/citations?user=THEIR_USER_ID
  (Find their ID by going to their Scholar profile - it's in the URL after "user=")
- LinkedIn: https://linkedin.com/in/their-username
- ORCID: https://orcid.org/their-orcid-id
- ResearchGate: https://researchgate.net/profile/Their-Name

You can have as many or as few links as needed per person. Just delete the 
<a> tags you don't need.

📚 ADDING PUBLICATIONS
================================================================================

1. Open: publications.html
2. Find the correct year section (or create a new one)
3. Add a new publication:

   <div class="publication">
       <p class="pub-authors">Last, F., Last, F., & Last, F.</p>
       <p class="pub-title">Your paper title here.</p>
       <p class="pub-venue"><em>Journal Name</em>, Volume(Issue), Pages.</p>
       <a href="https://doi.org/xxxxx" class="pub-link">DOI →</a>
   </div>

To add a new year section:
   <div class="pub-year">
       <h2>2027</h2>
       <!-- publications go here -->
   </div>

🆘 IF SOMETHING BREAKS
================================================================================

1. Check for missing closing tags (</div>, </section>, etc.)
2. Make sure quotes are balanced in HTML attributes
3. Clear your browser cache (Ctrl+Shift+R or Cmd+Shift+R)
4. Check the browser console (F12) for error messages
